# OPG–T2D Mendelian randomization analyses

This repository contains the R scripts used to evaluate the association between genetically predicted circulating osteoprotegerin (OPG) and type 2 diabetes (T2D), including primary Mendelian randomization (MR), colocalization, an alternative two-sample MR analysis, secondary MR analyses of glycemic traits, and two-step MR mediation analysis using HOMA-B.

## Repository structure

```text
.
├── README.md
├── 01_data_processing.R
├── 02_primary_mr.R
├── 03_coloc.R
├── 04_alternative_two_sample_mr.R
├── 05_secondary_mr.R
├── 06_mediation.R
├── data/
└── results/
```

All scripts are intended to be run from the repository root.

## Data sources

Seven source datasets are used in the analyses. Six require local summary-statistics files, whereas the SCALLOP OPG pQTL instruments are obtained through the OpenGWAS API.

| Data source | Main use | Access in code |
|---|---|---|
| SCALLOP OPG pQTL | Instrument identification for the primary MR | OpenGWAS API (`ebi-a-GCST90012002`) |
| UKB-PPP OPG pQTL | OPG exposure estimates, colocalization, alternative MR | Local file |
| T2DGGI T2D GWAS | T2D outcome associations | Local file |
| HOMA-B GWAS | Two-step MR mediation | Local file; HOMA-B instruments for path b are also extracted from OpenGWAS (`ieu-b-117`) |
| MAGIC fasting glucose GWAS | Secondary MR | Local file |
| MAGIC fasting insulin GWAS | Secondary MR | Local file |
| MAGIC HbA1c GWAS | Secondary MR | Local file |

Therefore, the six locally required raw/source datasets are:

1. UKB-PPP OPG pQTL
2. T2DGGI T2D GWAS
3. HOMA-B GWAS
4. MAGIC fasting glucose GWAS
5. MAGIC fasting insulin GWAS
6. MAGIC HbA1c GWAS

Raw summary-statistics files are not distributed with this repository. Users should obtain the data from the corresponding source studies/resources and comply with their data-use requirements.

## Input and processed data files

Some scripts use analysis-specific subsets derived from the source datasets. These files are **processed inputs and should not be interpreted as additional data sources**.

### `01_data_processing.R`

Source/local inputs:

```text
data/UKB_100kb_0_1_only_for_SCALLOP.csv
data/EUR_Metal_LDSC-CORR_Neff.v2.txt
```

The script also retrieves SCALLOP instruments from OpenGWAS and creates:

```text
data/SCALLOP_OPG_cis_instruments.csv
data/primary_OPG_exposure.csv
data/primary_T2D_outcome.csv
```

### `02_primary_mr.R`

Uses the processed files generated by `01_data_processing.R`:

```text
data/primary_OPG_exposure.csv
data/primary_T2D_outcome.csv
```

### `03_coloc.R`

Uses analysis-specific subsets derived from UKB-PPP and T2DGGI:

```text
data/coloc_OPG_pQTL_chr8.csv
data/coloc_T2D_GWAS_chr8.csv
```

These are not independent data sources; they are prepared from the UKB-PPP OPG pQTL and T2DGGI datasets, respectively.

### `04_alternative_two_sample_mr.R`

Uses:

```text
data/TNFRSF11B_O00300_OID20735_v1_Inflammation_chr8.csv
data/alternative_T2D_outcome.csv
```

The first file is derived from the UKB-PPP OPG pQTL source data, and the second is derived from the T2DGGI source data.

The script performs OPG variant filtering, LD clumping, harmonization, and radial MR. It then excludes `rs1485286`, which was identified as the outlier in the original radial MR analysis, and creates:

```text
results/alternative_two_sample_mr/alternative_OPG_exposure_rs1485286_excluded.csv
```

This generated file is then re-read and used for the final alternative two-sample MR analysis.

### `05_secondary_mr.R`

Uses the OPG exposure data generated in `01_data_processing.R` together with three MAGIC GWAS files:

```text
data/primary_OPG_exposure.csv
data/MAGIC1000G_FG_EUR.tsv
data/MAGIC1000G_FI_EUR.tsv
data/MAGIC1000G_HbA1c_EUR.tsv
```

### `06_mediation.R`

Uses:

```text
data/primary_OPG_exposure.csv
data/mediation_HOMA_B_GWAS.tsv
data/mediation_T2D_GWAS_EUR.csv
results/primary_mr/primary_mr_results.csv
```

`primary_OPG_exposure.csv` is generated by `01_data_processing.R`, and `primary_mr_results.csv` is generated by `02_primary_mr.R`. The T2D mediation file is an analysis-specific subset of the T2DGGI data.

For the HOMA-B → T2D path, HOMA-B instruments are additionally extracted from OpenGWAS using GWAS ID `ieu-b-117`.

## Analysis workflow

### 1. Data processing

`01_data_processing.R`

- Extracts genome-wide significant SCALLOP OPG instruments through OpenGWAS.
- Restricts instruments to the OPG cis region.
- Matches the selected instruments to UKB-PPP OPG pQTL estimates.
- Extracts the corresponding T2DGGI outcome associations.

### 2. Primary MR

`02_primary_mr.R`

- Harmonizes OPG and T2D associations.
- Calculates individual and overall F-statistics.
- Performs fixed-effect inverse-variance weighted (IVW) MR as the primary analysis.
- Performs weighted median and MR-Egger analyses as sensitivity analyses.
- Evaluates heterogeneity, the MR-Egger intercept, single-SNP estimates, leave-one-out analyses, and Steiger directionality when the required information is available.

### 3. Colocalization

`03_coloc.R`

- Defines the OPG cis region.
- Aligns OPG pQTL and T2D variants.
- Performs approximate Bayes factor colocalization using `coloc::coloc.abf`.

### 4. Alternative two-sample MR

`04_alternative_two_sample_mr.R`

- Selects genome-wide significant UKB-PPP OPG cis-pQTLs.
- Performs LD clumping at `r² = 0.1` in Europeans.
- Harmonizes OPG and T2D data.
- Performs radial IVW and radial MR-Egger analyses.
- Excludes `rs1485286` following the original radial MR outlier analysis.
- Performs the final alternative two-sample MR and sensitivity analyses.

### 5. Secondary MR

`05_secondary_mr.R`

Evaluates genetically predicted circulating OPG in relation to:

- fasting glucose,
- fasting insulin, and
- HbA1c.

### 6. Mediation analysis

`06_mediation.R`

Performs two-step MR mediation analysis for:

```text
OPG → HOMA-B → T2D
```

The indirect effect is estimated using the product-of-coefficients approach. A 95% confidence interval is calculated for the indirect effect. The mediation proportion is reported as a point estimate only; a confidence interval for the mediation proportion is not calculated in this script.

# install.packages("remotes")

## OpenGWAS authentication

`01_data_processing.R` and `06_mediation.R` access OpenGWAS. Set an OpenGWAS JWT in `.Renviron` before running these scripts:

```text
OPENGWAS_JWT=your_token_here
```

Do not commit `.Renviron` or authentication tokens to a public repository.

## Running the analyses

From the repository root:

```bash
Rscript 01_data_processing.R
Rscript 02_primary_mr.R
Rscript 03_coloc.R
Rscript 04_alternative_two_sample_mr.R
Rscript 05_secondary_mr.R
Rscript 06_mediation.R
```

`06_mediation.R` should be run after `02_primary_mr.R` because it uses the primary OPG → T2D MR estimate as the total effect.

## Output directories

Analysis results are written to:

```text
results/
├── primary_mr/
├── colocalization/
├── alternative_two_sample_mr/
├── secondary_mr/
└── mediation/
```

Each analysis script also saves `sessionInfo.txt` where applicable to facilitate reproducibility.

## Reproducibility note

The repository contains analysis code but does not redistribute the underlying GWAS or pQTL summary statistics. File names in `data/` reflect the analysis-specific files used in the original workflow. Users reproducing the analyses from source datasets should prepare equivalent files with the required columns and update file paths where necessary.
